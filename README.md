# iNew: bản cài đặt

Kho này chỉ chứa file cài đặt iNew, không có mã nguồn. Tải bản mới nhất ở mục **Releases** → **Latest**.

| Máy | File | Yêu cầu |
|---|---|---|
| Windows | `iNew-Setup-x.y.z.exe` | Windows 10 hoặc 11, 64-bit |
| Mac chip Apple (M1, M2, M3…) | `iNew-x.y.z-macOS-arm64.dmg` | macOS 14 trở lên |
| Mac chip Intel | `iNew-x.y.z-macOS-x86_64.dmg` | macOS 13.4 trở lên |

Hướng dẫn cài đặt nằm trong file `HUONG_DAN_CAI_DAT.md` đính kèm mỗi bản phát hành. iNew đã cài sẽ tự báo khi có bản mới.

iNew miễn phí cho cộng đồng làm tin. Mỗi máy cần một mã bản quyền, nhận miễn phí qua Telegram ngay trong phần mềm (trang **Bản quyền**).
